# Milestone 14: Closed-System Liquidity Observability & Bitemporal Canonical Observations

**Phases:** 306 – 325  
**Domain:** Universal Bitemporal Narrow-Long Parquet Lakehouse (`MetricObservation`), Mandatory Per-Row Source Provenance, 100% Zero-API-Key Liquidity & Flow Ingestion, Dynamic Wide Matrix Pivot API, & Stage-1 Implied Net Flow Plumbing.  
**Primary Goal:** Memampukan `economy-aggregator` mengumpulkan seluruh proksi arus modal riil, likuiditas dolar/kripto, posisi lindung nilai, dan penyusutan leverage secara otomatis tanpa ketergantungan API key berbayar — sekaligus menyimpan **asal-usul sumber (*provenance*)** pada setiap titik data.

## 2. Arsitektur Persistensi Umum (Bitemporal Canonical Narrow-Long Parquet)

1. **Tabel Kanonis Tunggal (`observations`):**
   - Menampung seluruh seri non-OHLCV (makro, arus ETF, on-chain, stablecoin, OI, COT, margin debt, serta hasil komputasi *derived*) dalam format **Narrow-Long (Tall)** agar penambahan metrik baru tidak pernah membutuhkan migrasi kolom Parquet.
   - Lokasi Hive: `data/lake/observations/domain=<domain>/series_id=<series_id>/year=<YYYY>/chunk_*.parquet`
   - Kompresi `ZSTD(3)`, *Dictionary Encoding* aktif, terurut lokal `(observation_ts_utc ASC, known_at_utc DESC)` untuk *RowGroup pruning*.
2. **Bitemporal Anti-Lookahead:**
   - Menyimpan pasangan `(observation_ts_utc, known_at_utc, revision_seq)` secara *append-only* untuk mendukung query historis `as_of_known_at`.
3. **Jaminan Provenance 100% Wajib (`Zero Anonymous Data` & `Zero Cross-Source Mixing`):**
   - Setiap baris wajib membawa `source`, `source_series_id`, `source_url`, `source_tier`, `source_checksum`, dan `batch_id`. Writer memblokir penulisan jika ada atribut sumber yang kosong.
   - **Larangan Fallback Pencampur Sumber:** Sumber berbeda (mis. `dbnomics_fed` H.4.1 reserve factors vs `fed_h41_html` total assets; `coinmetrics_community` USD vs `github_ercindedeoglu` BTC; `ssga_xlsx` exact vs `stockanalysis` rounded) ditempatkan pada `series_id` terpisah (`source-scoped`) serta dikunci `(series_id, source, ts)`. Endpoint `/v1/observations/matrix` dan `/v1/market/candles` menerapkan fail-fast **`HTTP 409 Conflict`** jika ditemukan `>1` sumber tercampur dalam satu seri tanpa `?source=`, sementara `cli.rs` (*All-Weather* Binance → Yahoo) dan `analytics_routes.rs` (*static `canonical_seeds` fallback*) sudah diubah menjadi fail-fast ketat.
4. **Pivoting Dinamis di Memori (`/v1/observations/matrix`):**
   - Konversi ke format tabel lebar (tanggal × variabel) untuk konsumsi R (`ConnectednessApproach`) / Python (`statsmodels`) dilakukan saat query membaca/mengekspor, lengkap dengan ringkasan cakupan sumber (`sources_used`).

## 3. Granular Implementation Phases (Phase 306 – 325)

### Group A: Canonical Persistence & Dependency Compliance (Phase 306 – 310)
- **Phase 306:** Domain model `MetricObservation`, `SourceProvenance`, `SourceTier`, `ObservationFrequency`, & validator *Zero Anonymous Data* (`src/core/observation_types.rs`).
- **Phase 307:** Registry `SeriesCatalog` (`src/core/series_catalog.rs`) memetakan `series_id` ↔ kompartemen balon air, unit, frekuensi, dan rantai *primary/fallback sources*.
- **Phase 308:** Tambah crate berlisensi permisif (`calamine` MIT/Apache-2.0, `csv` MIT/Unlicense, `quick-xml` MIT) ke `Cargo.toml` + verifikasi nol CVE baru via `osv-scanner`.
- **Phase 309:** Apache Arrow schema & RecordBatch converter untuk `observations` (`src/features/storage/observation_schema.rs`) + resolver partisi tahunan di [partition.rs](file:///root/projects/economy-aggregator/src/features/storage/partition.rs).
- **Phase 310:** Bitemporal Append-Only `ObservationWriter`, `ObservationReader` (mendukung filter `as_of_known_at` & *revision resolution*), serta integrasi partisi `observations` ke [compactor.rs](file:///root/projects/economy-aggregator/src/features/storage/compactor.rs).

### Group B: Zero-Key Liquidity, Macro & TradFi Connectors (Phase 311 – 316)
- **Phase 311:** Konektor Resmi Pemerintah AS Bagian 1 — **US Treasury Fiscal Data** (TGA harian), **US Treasury Daily T-Bill CSV** (`DTB3`), & **NY Fed Markets API** (`ON RRP`) (`src/features/ingestion/liquidity/treasury.rs`, `nyfed.rs`).
- **Phase 312:** Konektor Resmi Pemerintah AS Bagian 2 — **OFR STFM API** (MMF) + **DBnomics `FED/H41`, `H8`, `H15`** + parser HTML Kamis **`federalreserve.gov/releases/h41/current/h41.htm`** (`src/features/ingestion/liquidity/ofr.rs`, `dbnomics.rs`, `fed_h41_html.rs`).
- **Phase 313:** Konektor Arus & Tonase **SSGA Official XLSX** (`navhist-us-en-spy.xlsx`, `navhist-us-en-gld.xlsx`) via `calamine` lengkap dengan SHA-256 checksum (`src/features/ingestion/flows/ssga_xlsx.rs`).
- **Phase 314:** Konektor **CFTC COT Socrata API** (`72hh-3qpy.json` & `6dca-aqww.json`) untuk Emas & OI Futures S&P 500/Nasdaq-100 (`src/features/ingestion/flows/cftc_cot.rs`).
- **Phase 315:** Konektor **StockAnalysis Daily ETF Snapshot** (`/etf/{ticker}/__data.json`) untuk `sharesOut` & `assets` harian `SPY`, `QQQ`, `IBIT`, `IAU` (`src/features/ingestion/flows/stockanalysis.rs`).
- **Phase 316:** Konektor Deleveraging TradFi — **OCC Daily Equity Options OI CSV** (`occ_oi.rs`) & **FINRA Margin Statistics Dynamic XLSX Scraper** (`finra_margin.rs`), plus default subscriptions Yahoo `^MOVE` & `DX-Y.NYB` di [subscription.rs](file:///root/projects/economy-aggregator/src/core/subscription.rs).

### Group C: Zero-Key Crypto Flow, Stablecoin & Leverage Connectors (Phase 317 – 320)
- **Phase 317:** Konektor **DefiLlama Stablecoins** (`stablecoins.llama.fi` all + USDT + USDC) (`src/features/ingestion/crypto_flows/defillama.rs`).
- **Phase 318:** Konektor **BGeometrics Open Endpoints** (`/v1/etf-flow-btc` & `/v1/open-interest-futures` multi-exchange breakdown) (`src/features/ingestion/crypto_flows/bgeometrics.rs`).
